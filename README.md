# esa TOC Sidebar

[esa](https://esa.io) の記事ページ上部にある目次を、画面右側の固定サイドパネルに表示する Chrome 拡張機能です。

## 機能

- 記事の目次を右側の固定サイドパネルに表示（元の目次エリアは非表示にし、本文を広く表示）
- スクロール位置に応じて、現在読んでいる見出しをハイライト
- 目次クリックでスムーズスクロール（固定ヘッダーの高さを考慮）
- パネル左端のドラッグで幅を変更（180〜600px、設定は保存）
- パネルの開閉（✕ で閉じ、「☰ 目次」ボタンで再表示。状態は保存）
- 「↑」ボタンでページ先頭へ移動
- 目次のないページではパネルを表示しない
- 記事の切り替え・編集による目次の変化に自動追従

## インストール

1. このリポジトリをクローンまたはダウンロード
   ```sh
   git clone https://github.com/Yuffter/esa-toc-sidebar.git
   ```
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を ON にする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このディレクトリを選択

## 対象ページ

`https://*.esa.io/*`

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `content.js` | サイドパネルの生成、目次の同期、現在位置のハイライト |
| `content.css` | サイドパネルとレイアウト調整のスタイル |
